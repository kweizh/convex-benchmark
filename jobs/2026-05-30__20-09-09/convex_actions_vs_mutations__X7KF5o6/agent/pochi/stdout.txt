Refactored `convex/tasks.ts` to properly separate Convex actions and mutations:

**Problem:** The original `addTaskWithApi` was a `mutation` that called `fetch()` — this fails because Convex mutations must be deterministic and cannot perform side effects like external API calls.

**Solution:** Split the logic into two properly-scoped functions:

1. **`fetchAndSave` action** — Actions are allowed to perform side effects like `fetch`. This action:
   - Fetches data from `https://jsonplaceholder.typicode.com/todos/1`
   - Parses the JSON response and extracts the `title` field
   - Calls the `saveTask` mutation via `ctx.runMutation(api.tasks.saveTask, { title: data.title })`
   - Returns the newly created task ID

2. **`saveTask` mutation** — Mutations handle deterministic database writes. This mutation:
   - Accepts a `title` argument (validated as `v.string()`)
   - Inserts a document into the `tasks` table with `title` and `isCompleted: false`
   - Returns the ID of the newly inserted document

The Convex backend will expose the action as `tasks:fetchAndSave` and the mutation as `tasks:saveTask`, both properly exported.
